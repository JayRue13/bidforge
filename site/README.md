# BidForge public site

Deploy the `site/` folder as a static site. The free estimator is the acquisition entry point; `/app/` is the matching public Pro app experience.

## Structure
- `free/index.html` — free estimator and paid-upgrade funnel
- `app/index.html` — mobile-first BidForge Pro app
- `app/manifest.webmanifest` — installable PWA metadata
