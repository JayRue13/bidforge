# Deploy BidForge free estimator

1. Create a GitHub account: https://github.com/signup
2. Create a public repository named `bidforge`.
3. Upload everything inside `site/` to the repository root.
4. Open Settings -> Pages.
5. Set the source to Deploy from a branch, choose `main` and `/ (root)`, and save.
6. Your free estimator will be served from the repository's GitHub Pages URL.

GitHub Pages is available on GitHub Free public repositories. See:
https://docs.github.com/en/pages/getting-started-with-github-pages
